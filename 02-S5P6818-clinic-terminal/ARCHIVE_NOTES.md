# 医路通归档说明

## 项目身份

项目全称为“基于 S5P6818 的联网智慧医疗自助服务终端”。系统由 S5P6818 LVGL 终端、Ubuntu epoll 服务器、TCP 单行 JSON 协议、业务 Core、SQLite Store 和管理员命令行工具组成。

## 主要入口

- 板端程序：`board/clinic_terminal/`
- 公共协议与 TCP：`common/`
- 业务逻辑：`core/`
- SQLite 数据层：`store/`
- Ubuntu 服务器：`server/`
- 主机客户端与管理员工具：`terminal/`
- 自动化测试：`tests/`
- 统一构建入口：`Makefile`
- 当前事实与验收边界：`docs/PROJECT_STATUS.md`、`docs/TEST_STATUS.md`、`docs/FINAL_ACCEPTANCE.md`

## 归档裁剪

- 排除了 `build/`、失效的 `.git`、编辑器配置和内部临时计划。
- `reference/six/six` 原副本约 474 MB；这里只保留 Makefile 实际使用的 LVGL 8.3 `src`、fbdev/evdev 驱动和 FreeType 头文件/库。
- 未复制许可未知的 `simkai.ttf`。目标板历史运行路径为 `/font/simkai.ttf`，重新部署时应替换为许可明确的中文字体。
- 保留 `reference/s5p6818_platform_kit`，用于记录开发板环境、已知事实和未知项。

归档不改变原项目，也不把历史用户反馈描述成本次重新验证结果。

## 安全边界

这是教学演示系统。SQLite 用户密码和板端“记住密码”文件使用明文保存；测试源码中的用户名和口令均为演示数据。公开学习时可以讨论这一限制，但不得将当前实现直接用于生产医疗或真实账号系统。
