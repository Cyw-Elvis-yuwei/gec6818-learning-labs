## 证据口径

- “源码存在”只表示文件已归档。
- “静态检查”不等于编译通过。
- 历史构建、运行或真机反馈会明确标注日期和证据完整性。
- 没有重新执行的项目不会写成“当前版本已验证”。

## 归档原则

- 原始工程只读，不覆盖、不删除。
- 排除对象文件、构建目录、重复备份和发布压缩包。
- 未确认许可的字体和第三方素材不进入合集。
- 必需的第三方源码或库只保留实际构建需要的最小集合，并保留其许可证文件。
