# 管理员商品 CRUD 测试流程

## 1. 管理员登录测试

1. 启动程序并进入售票主页面。
2. 点击“管理员”按钮。
3. 输入错误账号或密码，应提示账号或密码错误。
4. 输入 `admin / 123456`，应进入商品管理页面。

## 2. 商品管理页面布局测试

1. 左侧列表应显示全部商品名称、售价、库存。
2. 右侧应有四个按钮：新增商品、删除商品、修改商品、查询商品。
3. 列表内容不能与按钮重叠。
4. 所有弹窗应在键盘上方显示，输入时不能被键盘完全遮挡。

## 3. 新增商品测试

1. 点击“新增商品”。
2. 输入商品名称、售价、库存、图片 ID。
3. 点击保存。
4. 管理页列表应立即出现新商品。
5. 主页面翻页后应能看到新商品。
6. 关闭程序并重新开机，新商品仍应存在。

## 4. 删除商品测试

1. 点击“删除商品”。
2. 输入已有商品名称。
3. 点击删除。
4. 管理页列表和主页面应立即移除该商品。
5. 关闭程序并重新开机，被删除商品不应恢复。

## 5. 修改商品测试

1. 点击“修改商品”。
2. 输入已有商品名称。
3. 可先点“查询”读取当前商品价格、库存、图片 ID。
4. 输入新的价格、库存、图片 ID。
5. 点击保存。
6. 管理页列表和主页面应立即显示新价格和库存。
7. 重启设备后，修改结果仍应存在。

## 6. 查询商品测试

1. 点击“查询商品”。
2. 输入已有商品名称，应显示名称、售价、库存、图片 ID。
3. 输入不存在商品名称，应提示商品不存在。

## 7. 循环稳定性测试

连续执行以下流程不少于 5 轮：

```text
登录 -> 翻页查看商品 -> 加购 -> 付款 -> 管理员登录 -> 新增 -> 修改 -> 查询 -> 删除 -> 重启验证
```

重点观察：

- 是否有弹窗错位。
- 是否有键盘遮挡。
- 是否有数字计算错误。
- 是否有程序卡死。
- 商品数据重启后是否仍然存在。
