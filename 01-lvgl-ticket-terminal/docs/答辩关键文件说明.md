# 景区门票自助售票系统：答辩关键文件说明

## 一、明天答辩最关键的文件

| 文件 | 答辩时怎么说 |
|---|---|
| `ui_main.c` | 主页面入口，负责读取商品数据、创建售票主界面，并接入管理员入口。 |
| `ui_goods_view.c/.h` | 商品展示页面，负责显示商品图片、名称、售价、库存、上一页/下一页。 |
| `ui_buy_dialog.c/.h` | 购买弹窗，点击商品后弹出，用加减按钮选择数量，不用手输数字。 |
| `ui_pay_dialog.c/.h` | 付款弹窗，负责显示付款信息和微信/支付宝二维码区域。 |
| `ui_admin_dialog.c/.h` | 管理员专属登录弹窗，只有账号密码正确才能进入后台。 |
| `ui_admin_page.c/.h` | 管理员商品管理首页，显示商品列表和新增、删除、修改、查询四个按钮。 |
| `ui_admin_add_dialog.c/.h` | 新增商品小窗口，输入商品名、售价、库存、图片名并保存。 |
| `ui_admin_delete_dialog.c/.h` | 删除商品小窗口，根据商品名删除商品。 |
| `ui_admin_modify_dialog.c/.h` | 修改商品小窗口，修改商品售价、库存、图片名。 |
| `ui_admin_query_dialog.c/.h` | 查询商品小窗口，根据商品名查询商品信息。 |
| `ui_admin_goods_store.c/.h` | 管理员商品数据操作模块，真正负责新增、删除、修改、查询和写回文件。 |
| `ui_keyboard.c/.h` | 拼音输入法模块，负责点击输入框弹出拼音键盘。 |
| `ui_font.c/.h` | FreeType 字体模块，负责加载中文字体，解决中文显示问题。 |
| `ui_text.h` | 所有界面中文文本集中管理，方便统一修改。 |
| `ui_main_state.c/.h` | 全局状态模块，保存商品数组、购物车、页码和主页面控件指针。 |
| `lvgl/src/font/lv_100ask_pinyin_ime.c` | 拼音输入法词库文件，本包已修正项目常用景区候选字。 |
| `goods_utf8.txt` | 商品数据文件，程序重启后数据不丢失靠它保存。 |

## 二、老师可能问的问题

### 1. 你的系统实现了什么？
本系统是基于 LVGL 的景区门票自助售票界面，支持商品展示、购买数量选择、购物车、二维码付款、管理员登录和商品增删改查。

### 2. 商品数据为什么重启后不会消失？
因为商品数据不是只放在内存里，管理员新增、删除、修改后会调用 `ui_admin_goods_save_all()` 写回 `goods_utf8.txt` 文件。设备重启后，程序重新读取这个文件，所以数据还在。

### 3. 管理员页面怎么进入？
主页面点击“管理员”按钮，弹出 `ui_admin_dialog.c` 里的登录窗口，输入正确账号和密码后调用 `ui_admin_page_show()` 进入商品管理页面。

### 4. 中文为什么能显示？
项目使用 FreeType 加载 `/font/simkai.ttf` 字库，并通过 `set_ft()` 给 LVGL 控件设置中文字体。

### 5. 拼音输入法候选字为什么能输入景区名？
本包修正了 `lv_100ask_pinyin_ime.c`，把黄、山、西、湖、长、城、桂、林、张、家、界、鼓、浪、屿、九、寨、沟、兵、马、俑等项目常用字放到了对应拼音候选前面。
