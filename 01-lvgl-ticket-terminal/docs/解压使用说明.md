# 解压使用说明

## 1. 解压位置

把本压缩包解压到你的工程目录：

```bash
/mnt/hgfs/VMware_shared_folder/six
```

如果提示覆盖文件，选择覆盖。

## 2. 字体文件

本压缩包没有包含字体文件。你需要确认开发板上已有：

```bash
/font/simkai.ttf
```

如果你的字体和 demo 放在同一目录，请打开 `ui_font.c`，把：

```c
#define LV_FONT_KAI "/font/simkai.ttf"
```

改成：

```c
#define LV_FONT_KAI "./simkai.ttf"
```

## 3. Makefile 要包含的源文件

```make
ui_main.c ui_main_state.c ui_font.c ui_msgbox.c ui_keyboard.c ui_qr_display.c ui_pay_dialog.c ui_buy_dialog.c ui_goods_view.c ui_admin_dialog.c ui_admin_page.c ui_admin_goods_store.c ui_admin_add_dialog.c ui_admin_delete_dialog.c ui_admin_modify_dialog.c ui_admin_query_dialog.c
```

`ui_admin_manage.c` 是旧兼容文件，可以不加。加了也不会影响，但不要重复添加同一个 `.c` 文件。

## 4. 编译

```bash
make clean
make -j$(nproc)
```

## 5. 管理员账号

```text
账号：admin
密码：123456
```

## 6. 数据持久化

商品数据默认写回：

```text
goods_utf8.txt
```

管理员新增、删除、修改商品后，关闭设备再开机，数据仍应存在。
