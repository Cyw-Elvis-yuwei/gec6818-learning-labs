# 拼音词库修改说明

你之前把景区词条整体插入到 `kui` 后面，这样会破坏输入法的首字母索引。

本包采用正确做法：

1. 删除错误插入的整块词条。
2. 不打乱词库 a-z 顺序。
3. 只修改原来已经存在的拼音条目。
4. 把项目常用字放到候选最前面。

已处理的项目常用字包括：

```text
黄、山、风、景、区、西、湖、长、城、桂、林、水、张、家、界、鼓、浪、屿、九、寨、沟、兵、马、俑
```

替换路径：

```text
lvgl/src/font/lv_100ask_pinyin_ime.c
```

替换后必须重新编译：

```bash
make clean
make -j$(nproc)
```
