# LVGL 景区门票自助售票终端

## 项目目标

在嵌入式 Linux 设备上使用 LVGL 8.3 构建 800×480 景区门票自助售票界面，覆盖登录注册、商品展示、购买付款界面和管理员商品管理。

## 主要技术

- LVGL 8.3、Linux framebuffer、evdev
- C99、Make、ARM Linux 交叉编译
- FreeType 中文字体接口
- 文本文件保存用户与商品数据

## 代码入口

- 主入口：`src/core/main.c`
- 登录注册：`src/login/`
- 商品数据：`src/data/`
- 售票主界面：`src/main_ui/`
- 管理员功能：`src/admin/`
- 通用 UI：`src/common/`
- 构建入口：`Makefile`

## 构建说明

历史 Makefile 使用 `arm-linux-gcc`，并依赖归档中的 LVGL、lv_drivers 和 FreeType。原项目使用 `/font/simkai.ttf` 显示中文；该字体的许可来源未确认，因此未收入本合集。重新构建和部署前应使用许可明确的中文字体，并确认目标板字体路径。

## 安全边界

这是教学演示代码：管理员账号口令写在源码中，普通用户信息也由本地文本文件保存，不适合生产环境。归档中的固定口令只是演示数据，不应复用为任何真实账号密码。
